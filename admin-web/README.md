# 智慧社区 · Web 管理后台

按 Axure 原型重建双端后台：

| 端 | 原型 | 说明 |
|----|------|------|
| 管理端 | [2270660](https://www.axureshop.com/ys/2270660) | PC 运营管理端：驾驶舱、基础信息、物业、缴费、招商、物联、报表、系统 |
| 物业端 | [2317513](https://www.axureshop.com/ys/2317513) | 物业工作端（Web 化）：看板、住户、迁入迁出、报修、缴费、访客、巡检、维保 |

## 启动

```bash
cd admin-web
npm install
npm run dev
```

打开 http://localhost:5173 ，登录时选择「管理端」或「物业端」。
