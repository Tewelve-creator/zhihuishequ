# AI 智慧社区服务助手 · 主要功能介绍

> 多社区 SaaS · Spring Cloud 微服务 · UniApp（居民/物业）+ Vue3 管理后台  
> 仓库：https://gitee.com/zhihuo_1/zhihuishequ

---

## 一、产品概述

本系统面向物业公司与社区居民，提供「一平台多社区」的智慧物业与生活服务能力。平台按租户（社区）隔离数据，通过套餐功能码控制可用模块；同一套代码支撑三类门户：

| 端 | 使用者 | 入口 |
|----|--------|------|
| **物业工作端** | 物业管理员、网格员 | 管理后台 `/property/*` + App 物业态 |
| **居民端** | 业主 / 住户 | UniApp（H5 / 小程序） |
| **SaaS 运营端** | 平台运营 | 管理后台 `/admin/saas/*` |
| **商户端** | 社区超市商户 | 管理后台 `/merchant/*` |

技术栈概要：Gateway + Auth / Repair / AI / Stats / SaaS 等微服务；MySQL + Redis + MinIO；前端 Vue3 Element Plus 与 UniApp。

## 三、物业工作端（管理后台）

### 3.1 工作台与数据大屏

| 功能 | 说明 |
|------|------|
| **工作台** | 本社区待办概览、快捷入口、运营摘要 |
| **数据大屏（社区运营驾驶舱）** | 全屏可视化：工单汇总/趋势、活跃住户、待处理仪表盘、工单类型分布、服务质量排行；中间 **楼栋态势** 为数字孪生演示场景；底部社区动态（预警）与最新事件（真实接口数据） |

> 大屏依赖套餐功能码 `data_dashboard`。

### 3.2 住户与房屋

| 功能 | 说明 |
|------|------|
| 楼栋信息 | 维护小区楼栋档案 |
| 房屋档案 | 单元 / 房号 / 房屋基础信息 |
| 业主住户 | 业主与同住人档案、关联房屋 |
| 租客管理 | 租客信息维护 |
| 访客预约通行 | 审核与管理访客预约 |

### 3.3 车辆与停车

| 功能 | 说明 |
|------|------|
| 车位档案 | 车位绑定与档案 |
| 业主车辆 | 车牌、车主、房屋绑定 |
| 临时通行记录 | 临停 / 通行流水 |
| 停车收费台账 | 停车相关费用记录 |

### 3.4 迁入迁出审批

申请列表 → 审批处理 → 历史记录 → 迁移统计，覆盖住户迁入迁出全流程。

### 3.7 社区商超（物业侧）

| 功能 | 说明 |
|------|------|
| 商户列表 / 商超总订单 | 本社区商户与订单总览 |
| 超市入驻初审 | 商户入驻审核 |
| 本小区超市总览 | 运营概览 |

活动列表、报名管理、活动分类、活动统计。

## 四、居民 App（UniApp）

### 4.1 登录与房屋

- 手机号登录 / 注册  
- **房屋绑定与切换**：多套房切换当前房屋，业务单据关联房屋位置  

### 4.2 首页与消息

- 首页服务入口、公告摘要  
- 消息中心：站内消息列表与已读  

### 4.3 报修与反馈

- 提交报修（文字、图片、房屋位置）  
- 工单列表 / 详情 / 进度  
- 意见反馈  

### 4.4 缴费

- 待缴账单、确认支付、支付结果  
- 电子收据、缴费记录  

### 4.5 访客通行

- 发起访客预约、通行码 / 分享、预约列表  

### 4.6 AI 智能管家

- 社区知识问答（RAG / 知识库）  
- 业务意图辅助（如引导报修确认）  
- AI 识图辅助报修（可选真实视觉模型）  
- 情绪倾诉入口与引导  

### 4.7 生活服务

| 模块 | 能力 |
|------|------|
| 社区商城 | 逛店、购物车、下单、支付结果、我的订单 |
| 社区活动 | 活动列表、详情、报名 |
| 失物招领 | 发布 / 浏览寻物与招领 |
| 邻里动态 | 发帖、互动；邻里互助 |
| 公告 | 列表与详情 |
| 车辆 | 我的车辆登记（绑定房屋） |
| 智能日程 | 日程查看与管理 |

### 4.8 我的

个人资料、设置、修改密码、套餐相关入口等。

## 九、AI 能力说明

| 能力 | 业务价值 |
|------|----------|
| **智能问答** | 基于社区知识库回答制度、办事指引；支持本地 RAG |
| **识图报修** | 上传故障图片识别问题类型，辅助填单 |
| **业务意图** | 对话中识别报修等意图并引导确认提交 |
| **情绪调解** | 识别倾诉情绪，生成预警工单供物业跟进 |
| **失物匹配** | 寻物与招领智能匹配（按套餐开通） |
| **知识库管理** | 物业上传文档，分类、切分、索引供问答检索 |

默认 `ai.provider=mock` 可本地演示；可切换通义等 HTTP 模型（需配置 API Key，勿入库）。

## 十二、典型业务闭环（举例）

1. **报修闭环**：居民 App 提交（可含 AI 识图）→ 物业分派 → 网格员处理 → 完结；大屏统计与最新事件同步展示。  
2. **缴费闭环**：物业开账单 → 居民确认支付 → 流水 / 收据可查；欠费可汇总催缴。  
3. **访客闭环**：居民预约 → 物业审核 → 访客通行凭证。  
4. **商超闭环**：商户上架 → 居民下单 → 履约 → 物业/平台佣金结算。  
5. **AI 问答闭环**：物业维护知识库 → 居民问管家 → 日志可回溯。
