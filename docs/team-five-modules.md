# 智慧社区 · 五人功能分工文档

按五人划分。每人一块**主责模块**，其余功能拆入五份中。

---

## 总览

| 成员 | 主责模块 | 顺带负责（其余功能拆入） |
|------|----------|--------------------------|
| 第一人 | **报事报修** | 临时访客、巡检运维与设备、物业/网格员移动待办 |
| 第二人 | **缴费管理** | 收款通知、SaaS 套餐订单与财务退款、营收对账 |
| 第三人 | **社区商户** | 社区活动、居民车辆、公告通知 |
| 第四人 | **邻里倾诉** | 失物招领、房屋住户与迁入迁出、消息中心 |
| 第五人 | **AI** | 多租户登录与权限、运营驾驶舱与双端门户骨架、系统配置监控 |

---

## 第一人｜报事报修（主）

### 主责：报事报修
- 居民端：提交报修、上传图片、查看进度与详情
- 物业端：工单列表、指派网格员、处理、完结
- 状态流转：待处理 → 处理中 → 已完结
- 与 AI 识图报修的对接入口（识图结果可一键带入报修单）

### 兼管：临时访客
- 访客预约、核销
- 物业端访客管理

### 兼管：巡检运维与设备
- 巡检点位、巡检任务下发与执行
- 现场打卡、拍照、隐患记录
- 设备台账、维保计划与到期提醒
- 维保记录录入

### 兼管：移动工作台待办
- 物业 / 网格员 App 工作台
- 待处理工单、待巡检、待维保汇总

---

## 第二人｜缴费管理（主）

### 主责：缴费管理
- 物业端：账单开具、缴费项目管理
- 居民端：待缴账单、确认支付、支付结果、收据、缴费记录
- 支付通道预留（微信 / 支付宝；当前可为演示支付）
- 账单状态：待缴 / 支付中 / 已缴 / 失败

### 兼管：收款通知
- 催缴 / 收款相关通知发布与查看

### 兼管：SaaS 订单与财务
- 套餐新购 / 续费 / 升级订单
- 模拟或真实支付入账后生效（延租期、解锁功能）
- 财务与营收统计
- 退款及对账

---

## 第三人｜社区商户（主）

### 主责：社区商户
- 商户信息、商品分类与上下架
- 库存、售价、图片
- 居民端：浏览、购物车、下单
- 配送方式：送货上门 / 到店自提
- 起送金额校验
- 订单履约：接单、备货、配送、完成
- 退款申请与审核
- 未支付超时关单、库存回滚

### 兼管：社区活动
- 活动发布（标题、封面、时间、地点、人数）
- 居民报名、名额上限

### 兼管：居民车辆
- 车辆登记、绑定房屋、物业端车辆管理

### 兼管：公告通知
- 公告发布、定时发布
- 居民端公告列表与详情

---

## 第四人｜邻里倾诉（主）

### 主责：邻里倾诉 / 邻里圈
- 发帖（文字 / 图片）
- 点赞、评论
- 物业端动态管理与处理流转（待处理 / 处理中 / 已完结，如有工单化）
- 与 AI 情绪识别的对接入口

### 兼管：失物招领
- 寻物 / 招领发布与列表筛选
- 详情与图片预览
- 标记已找到等状态更新
- 与 AI 失物匹配的对接入口

### 兼管：房屋住户与迁入迁出
- 楼栋 / 单元 / 房号档案
- 住户档案
- 迁入迁出申请与物业审批
- 居民端房屋绑定 / 切换

### 兼管：消息中心
- 站内消息列表、已读

---

## 第五人｜AI（主）

### 主责：AI 智能服务
- AI 智能问答（制度 / 办事指引）
- AI 识图辅助报修
- 情绪倾诉识别与引导
- 失物智能匹配
- AI 知识库文档上传、切分与索引（RAG）
- 对话业务意图识别（如确认报修）
- AI 调用额度与限流
- Mock / 真实大模型切换

### 兼管：基础平台与多租户（登录权限侧）
- 手机号密码登录（管理端 / App）
- 登录选择所属社区（开通后同步）
- 角色：居民、网格员、物业管理员、平台运营
- 菜单与权限
- 租户开通、管理端账号密码、套餐功能码
- 租户到期预警 / 降级 / 冻结
- 多租户数据隔离
- 平台账号、登录与操作日志

### 兼管：数据驾驶舱与门户骨架
- 运营数据驾驶舱（KPI、中国地图社区分布）
- 套餐分布、订单结构、营收趋势、活跃 TOP
- 微服务运行监控入口、系统参数配置
- App / 管理后台登录页与整体导航骨架（与各业务页对接）

---

## 协作边界（避免重复踩坑）

| 事项 | 说明 |
|------|------|
| AI ↔ 报修 | 第五人出识图/意图接口；第一人接「确认生成报修单」 |
| AI ↔ 邻里 / 失物 | 第五人出情绪、匹配接口；第四人接页面展示 |
| 缴费 ↔ SaaS 订单 | 第二人统一支付与入账状态机口径 |
| 商户 ↔ 活动公告 | 第三人负责「内容与经营」类页面风格统一 |
| 公共登录 / 租户 | 第五人维护底座；其他人业务接口必须带租户隔离 |
